How to use one

Copy the template plus tokens.css and base.css. Everything colour, spacing and radius is already a variable, so a theme change is one file.

The Light/Dark switch at the top is a development affordance. In production, set data-mode on the <html> element and drop mode.js.

Type is Manrope, and it ships with the kit in fonts/ — every weight, every machine, no install needed.
